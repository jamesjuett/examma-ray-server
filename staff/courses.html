Add Sections

For now, we assume you're working with EECS 280.

Sections CSV should have these columns (headings and example data shown):

  • section_id (e.g. "12", "lab_12", anything as long as they are consistent and unique)
  • section_name (e.g. "Lab Section 12", "12, Tu 8:30AM - 10:30AM, 2150 DOW", only used for human-readable display)

If a section already exists with the given ID, it will be updated with the new name.

Upload Roster

For now, we assume you're working with EECS 280.

Roster CSV should have these columns (headings and example data shown):

  • email (e.g. "uniqname@umich.edu")
  • name (e.g. "FirstName LastName")
  • section_id (e.g. "lab_01") (these must match section IDs previously created for the course)

If a student belongs to multiple sections, there may be multiple rows with different section IDs (this won't be true for EECS 280 quizzes).

Roster upload will only work for admins (not all staff). If you're not an admin but need to add a student, add them inidividually.
